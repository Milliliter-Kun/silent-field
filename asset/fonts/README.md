# MiSans 字体说明

本项目使用小米 MiSans 字体，随页面本地加载官方原始 WOFF2 文件，无需用户安装或联网。

- 来源：https://hyperos.mi.com/font/download
- 官方字体包：https://hyperos.mi.com/font-download/MiSans.zip
- 许可协议：https://hyperos.mi.com/font-download/MiSans字体知识产权许可协议.pdf
- 引入字重：Regular、Semibold；未修改、转换或裁剪字体。
